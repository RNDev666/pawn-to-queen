# Pawn to Queen

Landing site for PawnToQueen chess coaching, served at [pawntoqueen.cc](https://pawntoqueen.cc).

Built with Next.js (static export), React, TypeScript and Tailwind CSS. Pushing to `main` deploys to GitHub Pages via `.github/workflows/deploy.yml`.

## Development

```bash
pnpm install
pnpm dev        # local dev server
pnpm check      # lint + typecheck
pnpm build      # static export to ./out
```
